Arquitectura de Extensiones: chrome.storage, Content Scripts y Atajos en Manifest V3

Novedades v1.1.0: Selecciona cualquier texto con el ratón. Aparecerá instantáneamente un mini-botón flotante [⚡ CLIP] con la directiva 45° clip-path de Carol. Al guardarlo, se creará un resaltado neón Electric Cyan automático con tooltip holográfico al pasar el cursor.

▶ TRES FORMAS DE CAPTURAR FRAGMENTOS:
1. Botón Flotante: Selecciona texto y haz clic en el botón amarillo flotante [⚡ CLIP].
2. Clic Derecho: Selecciona texto -> Clic derecho -> "⚡ Capturar fragmento a CyberClip".
3. Atajo de Teclado: Selecciona texto y pulsa Alt + C (Option + C en Mac).

Las extensiones construidas bajo Manifest V3 emplean Service Workers efímeros para responder a eventos del sistema como selecciones de texto y atajos de teclado sin consumir recursos en reposo.

La API chrome.storage.local proporciona almacenamiento asíncrono optimizado sin los bloqueos de renderizado de localStorage tradicional, permitiendo almacenar estructuras masivas de datos en segundo plano.

"Directiva Especial Carol: Bordes cortados a 45 grados con clip-path: polygon(0 0, calc(100% - 10px) 0, 100% 10px, 100% 100%, 10px 100%, 0 calc(100% - 10px))."

Al indexar fragmentos vinculados a esta URL, el content script inyecta resaltadores luminosos automáticos. Pasa el cursor por encima del texto resaltado en cian para ver el tooltip holográfico en tiempo real.

Tus notas y fragmentos pueden filtrarse por "Esta página" o consultarse en "Todo el banco de datos", con soporte instantáneo para exportación a Markdown (.md) y copias de seguridad en formato JSON.
